# Настройка Telegram уведомлений

## Проблема
При автоматическом деплое файл `telegram_config.php` удаляется, так как он исключен из Git (.gitignore).

## Решение
Настройка автоматического создания конфигурации через GitHub Secrets.

## Настройка

### 1. Создание Telegram бота
1. Напишите @BotFather в Telegram
2. Создайте нового бота: `/newbot`
3. Получите токен бота (сохраните его)

### 2. Получение Chat ID
1. Добавьте бота в группу или напишите ему лично
2. Перейдите по ссылке: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
3. Найдите `chat.id` в ответе

### 3. Добавление секретов в GitHub
1. Перейдите в Settings → Secrets and variables → Actions
2. Добавьте секреты:
   - `TELEGRAM_BOT_TOKEN`: токен вашего бота
   - `TELEGRAM_CHAT_ID`: ID чата для уведомлений

### 4. Автоматическое создание
При каждом push в `dev` ветку:
- Запускается деплой
- Автоматически создается `telegram_config.php` с актуальными секретами
- Файл размещается в правильной директории с корректными правами

## Структура конфига
```php
<?php
return [
    'TELEGRAM_TOKEN' => 'ваш_токен_бота',
    'CHAT_ID' => 'ваш_chat_id'
];
```

## Отладка
- Логи создания конфига записываются при деплое
- PHP логи с диагностикой доступны в логах сервера  
- В случае ошибки в ответе API будет поле `debug` с дополнительной информацией

## Безопасность
✅ Токены хранятся в GitHub Secrets (зашифрованы)  
✅ Файл конфига автоматически получает права 644  
✅ Конфигурация исключена из Git репозитория  
✅ Проверка существования директорий при создании
