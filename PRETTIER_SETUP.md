# Настройка Prettier для автоматического форматирования

## Что установлено

- **Prettier** - основной инструмент форматирования
- **@prettier/plugin-php** - плагин для форматирования PHP файлов
- Конфигурационные файлы для автоматического форматирования

## Файлы конфигурации

### .prettierrc
Основные настройки форматирования:
- Полуточия в конце строк
- Одинарные кавычки
- Ширина строки: 80 символов (PHP: 120)
- Отступы: 2 пробела (PHP: 4 пробела)

### .prettierignore
Файлы и папки, которые НЕ будут форматироваться:
- node_modules/
- vendor/
- Скомпилированные CSS/JS файлы
- Кэш и логи
- Системные файлы

### .vscode/settings.json
Настройки для автоматического форматирования в Cursor/VS Code:
- Форматирование при сохранении
- Prettier как форматтер по умолчанию
- Автоматическое исправление при сохранении

### .editorconfig
Дополнительные настройки редактора для единообразия

## Команды npm

```bash
# Проверить форматирование всех файлов
npm run format:check

# Отформатировать все файлы
npm run format

# Отформатировать с игнорированием неизвестных типов
npm run format:fix
```

## Автоматическое форматирование

### В Cursor/VS Code
1. Убедитесь, что установлено расширение "Prettier - Code formatter"
2. При сохранении файла (Ctrl+S / Cmd+S) код автоматически отформатируется
3. Настройки уже применены в `.vscode/settings.json`

### При коммите
Можно добавить pre-commit hook для автоматического форматирования:

```bash
# Установить husky и lint-staged
npm install --save-dev husky lint-staged

# Добавить в package.json
{
  "lint-staged": {
    "*.{js,jsx,ts,tsx,json,less,css,html,md,php}": "prettier --write"
  }
}
```

## Поддерживаемые типы файлов

- **JavaScript/TypeScript** - полная поддержка
- **PHP** - полная поддержка через плагин
- **LESS/CSS** - базовая поддержка
- **HTML** - базовая поддержка
- **JSON** - полная поддержка
- **Markdown** - полная поддержка

## Устранение проблем

### Prettier не форматирует PHP файлы
1. Убедитесь, что установлен `@prettier/plugin-php`
2. Проверьте, что в `.prettierrc` указан плагин

### Автоматическое форматирование не работает
1. Проверьте, что установлено расширение Prettier
2. Убедитесь, что в настройках указан Prettier как форматтер по умолчанию
3. Проверьте файл `.vscode/settings.json`

### Ошибки парсинга
1. Проверьте, что файл не в `.prettierignore`
2. Убедитесь, что тип файла поддерживается
3. Проверьте синтаксис файла

## Рекомендации

1. **Регулярно запускайте** `npm run format:check` для проверки
2. **Форматируйте перед коммитом** с помощью `npm run format`
3. **Настройте IDE** для автоматического форматирования при сохранении
4. **Используйте pre-commit hooks** для автоматического форматирования

## Обновление

```bash
# Обновить Prettier
npm update prettier

# Обновить плагины
npm update @prettier/plugin-php
```
